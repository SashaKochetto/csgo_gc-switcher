# CS:GO GC Switcher

Allows you to conveniently switch between different projects.

> [!CAUTION]
> This is an experimental project.
> Support for third-party anti-cheats (like GameGuard) is not guaranteed.
> **Only [these mods](#supported-mods) are supported!**

## How do use it
1. Download the [latest version](https://github.com/SashaKochetto/csgo_gc-switcher/releases/latest)
2. Extract the archive to the main CS:GO directory `csgo legacy`
3. Launch the `switcher`
4. Type `1` and press `Enter`
> [!WARNING]
> Make sure you have a clean version of CS:GO installed, without any mods!
> It is recommended to verify the game files in Steam.

5. Confirm the action by entering `y`, then pressing `Enter`

Great! You can now install mods (like PROJECT446, csgo_gc, etc.)!
And if you want to return to the vanilla version, just launch `switcher` and select the `Restore the vanilla version` option.

**But!** Do not forget that the project is experimental. And it might not fully provide the ability to switch between mods. However, this project works fine with [these mods](#supported-mods)!

## Supported mods
This project can be used with the following mods:
- [csgo_gc](https://github.com/Mikkokko/csgo_gc)
- [PROJECT446](https://project446.com)
